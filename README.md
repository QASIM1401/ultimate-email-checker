## ⚡ Quick Start

### 1. Install Dependencies

```bash
pip install colorama pysocks cryptography
```

### 2. Prepare Your File

Create a `.txt` file with email:password pairs:

```
user1@gmail.com:password123
user2@yahoo.com:mypassword
user3@outlook.com:securepass
```

### 3. Run the Checker

```bash
python ultimate_checker_v4_free.py
```

### 4. Enter File Path

When prompted, paste your file path and press Enter!

## 🐛 Known Issues & Fixes

<details>
<summary><b>🔧 Troubleshooting</b></summary>

<br>

### ❌ "Connection Timeout"
- Check internet connection
- Try different proxy
- Increase timeout in settings

### ❌ "Invalid Credentials"
- Verify email:password format
- Check for app password requirement
- Account may be locked

### ❌ "Too Many Connections"
- Reduce `max_threads` in settings
- Use proxies
- Wait a few minutes

</details>
